# Mapping between WISEDash Public's "GROUP_BY_VALUE" and StriveTogether's "population."

Mapping between WISEDash Public's "GROUP_BY_VALUE" and StriveTogether's
"population."

## Usage

``` r
GLOSSARY_OF_POPS_FOR_WISEDASH
```

## Format

### GLOSSARY_OF_POPS_FOR_WISEDASH

An object of class `spec_tbl_df` (inherits from `tbl_df`, `tbl`,
`data.frame`) with 13 rows and 3 columns.

- Population:

  `<chr>` a demographic group label used in the Civic Infrastructure
  Assessment

- GROUP_BY_VALUE:

  `<chr>` the value found in published WISEDash data

- Gender:

  `<chr>` Either "All", "Female", or "Male"
