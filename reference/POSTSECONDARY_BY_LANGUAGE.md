# Variables from the US Census to describe postsecondary completion by language spoken

Variables from the US Census to describe postsecondary completion by
language spoken

## Usage

``` r
POSTSECONDARY_BY_LANGUAGE
```

## Format

### POSTSECONDARY_BY_LANGUAGE

An object of class `spec_tbl_df` (inherits from `tbl_df`, `tbl`,
`data.frame`) with 12 rows and 7 columns.

- Group :

  `<chr>` the ACS table of this variable

- Index :

  `<int>` this variable's row in its ACS table

- Variable :

  `<chr>` the full specification of this variable for querying the API

- Education :

  `<chr>` the ACS vintage that this variable belongs to

- Employment :

  `<chr>` the labor force participation of people counted by this
  variable

- Language :

  `<chr>` use of English by people counted by this variable

- Status :

  `<chr>` the educational status of people counted by this variable
