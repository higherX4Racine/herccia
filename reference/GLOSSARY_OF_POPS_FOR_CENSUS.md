# Mapping from Census demographic categories to StriveTogether ones

Mapping from Census demographic categories to StriveTogether ones

## Usage

``` r
GLOSSARY_OF_POPS_FOR_CENSUS
```

## Format

### GLOSSARY_OF_POPS_FOR_CENSUS

An object of class `spec_tbl_df` (inherits from `tbl_df`, `tbl`,
`data.frame`) with 12 rows and 2 columns.

- Category:

  `<chr>` one of the OMB categories used by IPEDS

- Population:

  `<chr>` one of the categories used by StriveTogether
