# Column specification for data from WISEDash about student MAP percentile scores

Column specification for data from WISEDash about student MAP percentile
scores

## Usage

``` r
SPEC_FOR_WISEDASH_LOCAL_MAP_PERCENTILES
```

## Format

### SPEC_FOR_WISEDASH_LOCAL_MAP_PERCENTILES

A list of 16 name-datatype pairs

- Student ID:

  `<int>`

- Name:

  `<chr>`

- Status:

  `<chr>`

- Current School:

  `<chr>`

- Curr. Grade:

  `<chr>`

- Gender:

  `<chr>`

- Race/Ethnicity:

  `<chr>`

- EL:

  `<chr>`

- SPED:

  `<chr>`

- Percentile Score:

  `<chr>`

- Percentile:

  `<dbl>`

- Norm Lvl:

  `<chr>`

- School Year:

  `<chr>`
