# Identify which students met or exceeded their MAP growth goals

Identify which students met or exceeded their MAP growth goals

## Usage

``` r
predicate_MAP_percentile(.percentile)
```

## Arguments

- .percentile:

  `<chr[]>` a column of percentiles in `[0, 100]`

## Value

`<lgl[]>` `TRUE` when the input value is greater than 33.3
