# The literal row labels for different populations that StriveTogether wants

The literal row labels for different populations that StriveTogether
wants

## Usage

``` r
GLOSSARY_OF_POPS_FOR_CIA
```

## Format

### GLOSSARY_OF_POPS_FOR_CIA

An object of class `spec_tbl_df` (inherits from `tbl_df`, `tbl`,
`data.frame`) with 72 rows and 3 columns.

- CIA Year:

  `<int>` which year that Strive requested this combination of Gender
  and Population

- Gender:

  `<chr>` either "All", "Male", or "Female

- Population:

  `<chr>` some racial, ethnic, language-learner, and economic categories
