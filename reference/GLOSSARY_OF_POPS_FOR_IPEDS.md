# Mapping from IPEDS populations to StriveTogether ones

Mapping from IPEDS populations to StriveTogether ones

## Usage

``` r
GLOSSARY_OF_POPS_FOR_IPEDS
```

## Format

### GLOSSARY_OF_POPS_FOR_IPEDS

An object of class `spec_tbl_df` (inherits from `tbl_df`, `tbl`,
`data.frame`) with 27 rows and 4 columns.

- Sex:

  `<chr>` "all", "men", or "women", as per IPEDS

- Gender:

  `<chr>` "All", "Female", or "Male", as per StriveTogether

- Race/Ethnicity:

  `<chr>` one of the OMB categories used by IPEDS

- Population:

  `<chr>` one of the categories used by StriveTogether
