# IPEDS fields for calculating 150% graduation counts

IPEDS fields for calculating 150% graduation counts

## Usage

``` r
SEMI_JOINS_FOR_IPEDS
```

## Format

### SEMI_JOINS_FOR_IPEDS

An object of class `spec_tbl_df` (inherits from `tbl_df`, `tbl`,
`data.frame`) with 2 rows and 3 columns.

- Status:

  `<chr>` "Adjusted Cohort" "Completed"

- Relative Time:

  `<chr>` NA "\<=150%"

- Credential Earned:

  `<chr>` NA "Any"
