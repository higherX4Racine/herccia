# Group population and gender classes into three comparsions for visualization

Group population and gender classes into three comparsions for
visualization

## Usage

``` r
GLOSSARY_OF_POPS_FOR_COMPS
```

## Format

### GLOSSARY_OF_POPS_FOR_COMPS

An object of class `spec_tbl_df` (inherits from `tbl_df`, `tbl`,
`data.frame`) with 13 rows and 3 columns.

- Comparison:

  `<chr>` either "SES," "Gender," or "Race/Ethnicity"

- Gender:

  `<chr>` currently, Strive just uses two, plus "All"

- Population:

  `<chr>` a specific socioeconomic status, race/ethnicity, or gender
