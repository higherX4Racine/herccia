# Column specification for data from WISEDash about student growth in MAP scores

Column specification for data from WISEDash about student growth in MAP
scores

## Usage

``` r
SPEC_FOR_WISEDASH_LOCAL_MAP_GROWTH
```

## Format

### SPEC_FOR_WISEDASH_LOCAL_MAP_GROWTH

A list of 13 name-datatype pairs

- Student ID:

  `<int>`

- Name:

  `<chr>`

- Status:

  `<chr>`

- Current School:

  `<chr>`

- Curr. Grade:

  `<chr>`

- Gender:

  `<chr>`

- Race/Ethnicity:

  `<chr>`

- EL:

  `<chr>`

- SPED:

  `<chr>`

- Test Growth Result:

  `<chr>`

- Test Growth Period:

  `<chr>`

- Year:

  `<chr>`

- Test Growth Percentile:

  `<dbl>`
