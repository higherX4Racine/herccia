# Explain Census variables in terms of Sustainable Wage calculations

Explain Census variables in terms of Sustainable Wage calculations

## Usage

``` r
GLOSSARY_FOR_ACS_EMPLOYMENT
```

## Format

### GLOSSARY_FOR_ACS_EMPLOYMENT

an object of class `tbl_df`, `tbl`, `data.frame` with 21 rows and 4
columns

- Group :

  `<chr>` the table that the data come from, e.g. B01001

- Index :

  `<int>` the variable's row number in its table

- Gender :

  `<chr>` the gender that this row corresponds to

- Population:

  `<chr>` the socioeconomic group that this variable corresponds to
