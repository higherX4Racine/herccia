# Use this to semi-join Forward results and only get Strive-relevant data

Use this to semi-join Forward results and only get Strive-relevant data

## Usage

``` r
SEMI_JOINS_FOR_FORWARD
```

## Format

### SEMI_JOINS_FOR_FORWARD

An object of class `spec_tbl_df` (inherits from `tbl_df`, `tbl`,
`data.frame`) with 2 rows and 3 columns

- TEST_GROUP:

  `<chr>` "Forward"

- GRADE_LEVEL:

  `<chr>` "3" or "8"

- TEST_SUBJECT:

  `<chr>` "ELA" for 3rd grade and "Mathematics" for 8th
