# Identify which students met or exceeded their MAP growth goals

Identify which students met or exceeded their MAP growth goals

## Usage

``` r
predicate_MAP_growth(.test_growth_result)
```

## Arguments

- .test_growth_result:

  `<chr[]>` a column of verbal descriptions of MAP growth results

## Value

`<lgl[]>` `TRUE` when the input value es "Met Growth"
