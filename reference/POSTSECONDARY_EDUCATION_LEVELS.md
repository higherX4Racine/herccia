# Values of education levels from the US Census to describe postsecondary completion

Values of education levels from the US Census to describe postsecondary
completion

## Usage

``` r
POSTSECONDARY_EDUCATION_LEVELS
```

## Format

### POSTSECONDARY_EDUCATION_LEVELS

An object of class `spec_tbl_df` (inherits from `tbl_df`, `tbl`,
`data.frame`) with 28 rows and 4 columns.

- Order:

  `<num>` where the level occurs in the educational sequence

- Education:

  `<chr>` a human-readable description of the educational level

- Enrolled:

  `<lgl>` whether someone at this educational level should be considered
  as enrolled in postsecondary

- Completed:

  `<lgl>` whether someone at this educational level should be considered
  to have completed postsecondary
