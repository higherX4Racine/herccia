# herccia: Utilities for creating Civic Infrastructure Assessment reports

Perform the data tasks for a StriveTogether Civic Infrastructure
Assessment. Initially, this package focuses on public data from the US
Census and Wisconsin's Department of Public Instruction, and internal
data from Racine Unified School District.
